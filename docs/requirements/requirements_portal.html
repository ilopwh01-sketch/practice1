2. 요구사항 추적표

요구사항 ID를 기준으로 출처, 구현 산출물, 현재 상태, 검증 기준을 추적합니다.

ID 요구사항 출처 연결 산출물 상태 검증 기준
BR-01 07시-07시 기준 생산량, NG 수량, 불량률을 정확히 집계한다. 1차/2차 인터뷰 BRD, PRD, 대시보드 정의됨 보고서와 Excel에서 동일 기준 수량 확인
BR-02 CRACK/BUBBLE 불량 감소와 원인 파악을 핵심 목표로 둔다. 최종 인터뷰 BRD, KPI, 최종 산출물 예시 정의됨 Loss %, 재발 건수, 원인 후보 리드타임으로 측정
FR-01 생산 실적, 불량 이벤트, 설비 알람, Profile, 수기 메모 파일을 입력받는다. PRD 샘플 데이터, 데이터 설명서 정의됨 필수 컬럼 누락 시 검증 경고 표시
FR-02 설비/시간대별 NG 집중, Profile 이상, 알람 중첩을 탐지한다. PRD, 화면설계 대시보드 Heatmap, Timeline 정의됨 P1/P2/P3 우선순위가 화면에 표시됨
FR-03 AI 원인 후보는 1차 후보, 경쟁 가설, 추가 검증 항목으로 나누어 표시한다. 논문 RCA 보강 최종 산출물 예시, 논문 레퍼런스 정의됨 원인 확정 표현 없이 근거와 신뢰도 표시
FR-04 BOM/Recipe 조건별 평균, 표준편차, 반복 불량 히스토리를 관리한다. 최종 인터뷰 BRD, PRD, 최종 산출물 예시 정의됨 조건별 7일 평균, 표준편차, 반복 이력 표시
FR-05 논문 Failure Mode를 현장 데이터 컬럼과 연결한다. 메모장 요청 paper_reference, RCA 프레임워크, PRD 정의됨 Literature_Evidence_Matrix 출력
NFR-01 원본 데이터는 외부 반출하지 않고 로컬 또는 사내망에서 처리한다. 보안 조건 BRD, PRD 정의됨 외부 클라우드 분석은 파일럿 제외 범위로 표시
OPEN-01 DB/MES를 어디까지 활용할지 확정한다. 사용자 피드백 BRD 리스크, PRD 비기능 요구사항 미확정 사내 IT/MES 협의 후 범위 확정
OPEN-02 실제 실행 환경을 라인 PC, 사내망 PC, 별도 분석 PC 중 확정한다. 최종 인터뷰 미작성 항목 BRD, PRD 미확정 최종 제출 전 실행 환경 명시

3. 요구사항 변경 관리 흐름

사용자 피드백이 오면 아래 순서로 문서와 화면을 맞춰갑니다.

1. 피드백 수집질문 메모장 또는 대화에서 수정 요청 확인
2. 요구사항 등록요구사항 ID와 상태를 관리 포털에 반영
3. BRD/PRD 반영비즈니스 요구와 기능 요구로 분리
4. 산출물 반영대시보드, 화면설계, 데이터 설명서 수정
5. 검증포털 링크와 요구사항 추적표 확인

4. 요구사항 문서 운영 규칙

구분 관리 기준 대표 파일

제품/기능 요구 무엇을 입력받고, 어떤 기능과 화면을 제공할지 관리 PRD_Laminator_AI_Automation.md
