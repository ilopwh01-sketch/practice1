제품 개요 입력 데이터 기능 요구사항 화면 요구사항 이상 탐지 로직 출력물 수용 기준
Product Requirements Document

AI 일일 설비/불량 현황 보고서 자동 작성 도구

PRD는 자동화 도구가 어떤 데이터를 입력받고, 어떤 기능을 수행하며, 어떤 화면과 결과물을 제공해야 하는지 정의한다.

1. 제품 개요

주요 입력

생산 실적, 불량 이벤트, 설비 알람, Profile, 수기 메모

주요 출력

팀장 보고용 HTML, 데이터 분석용 엑셀

핵심 가치

CRACK/BUBBLE 조기 탐지, 원인 후보 도출

2. 입력 데이터 요구사항

데이터 파일 예시 주요 컬럼 사용 목적
생산 요약 daily_production_summary time_bucket, equipment_id, inspection_qty, ng_qty 07-07 집계, NG율, 설비/시간 집중
불량 이벤트 defect_events event_time, defect_code, inspection_tool 불량 Pareto, 동일 불량 집중 탐지
설비 알람 equipment_alarm alarm_time, alarm_code, severity 알람과 NG 집중 시간 연계
Profile laminator_profile_snapshot sample_time, cycle_time, temperature, vacuum 공정 time, 온도, 진공도 이상 확인
수기 메모 manual_memo 자유 텍스트 현장 맥락, 조치 사항, 인계 항목 반영

3. 기능 요구사항

FR-01 파일 업로드 및 검증

필수 컬럼, 날짜/시간, 숫자 컬럼, 07-07 범위를 검증한다.

  • 컬럼 누락 오류
  • 시간 파싱 오류
  • 데이터 기간 불일치 경고

FR-02 07-07 기준 집계

총 생산량, 검사량, NG 수량, NG율을 현장 기준으로 계산한다.

  • input/output/inspection 합계
  • 설비별 NG율
  • 시간대별 NG 수량

FR-03 불량 Pareto

CRACK, BUBBLE을 우선 관리 불량으로 표시하고 비중을 계산한다.

  • 불량 코드 내림차순
  • 전체 NG 대비 비중
  • 40% 이상 주요 불량 강조

FR-04 설비/시간 집중 분석

동일 설비/동일 불량 집중, 평균 대비 급증, 시간대 집중을 탐지한다.

  • 설비별 Bar Chart
  • 시간 Heatmap
  • P1/P2/P3 배지

FR-05 Profile 이상 탐지

공정 time, 온도, 진공도 이상을 불량 집중 시간과 연결한다.

  • 공정 time 10% 이상 증가
  • 온도 기준 이탈
  • 진공도 하락

FR-06 AI 원인 후보

불량 집중, Profile, 알람, 수량 검증 근거로 원인 후보를 제시한다.

  • High/Medium/Low 신뢰도
  • 근거 3개 이상 표시
  • 담당자 최종 승인

FR-07 문헌 근거 동적 매칭

CSV 업로드 후 주요 불량 모드에 맞는 논문 근거와 검증 항목을 다시 선택한다.

  • CRACK/BUBBLE/PID별 문헌 선택
  • 현장 데이터 신호와 문헌 연결
  • 추가 확인 컬럼 제안

4. 화면 요구사항

1. Overview KPI
2. 금일 핵심 이슈
3. 불량 Pareto
4. 설비/시간 Heatmap
5. Profile/알람 Timeline

첫 화면은 금일 핵심 이슈, P1 이상 징후, 최우선 AI 원인 후보, 조치 필요 사항을 가장 위에 배치한다.

5. 이상 탐지 및 신뢰도 로직

등급 기준 예시
High 불량 집중, Profile 이상, 설비 알람이 같은 시간대에 동시 확인 LAM-03 14시대 CRACK 집중 + 진공도 하락 + 압력 알람
Medium 불량 집중과 Profile 이상 또는 알람 중 2개 근거 연결 상부 온도 상승과 CRACK 집중 일부 겹침
Low 단일 근거만 있거나 수량 검증이 필요한 상태 재판정/재투입으로 인한 수량 불일치

6. 출력물 요구사항

팀장 보고용 HTML

  • Overview KPI 카드
  • 금일 핵심 이슈와 P1/P2/P3 표시
  • AI 원인 후보와 근거 데이터
  • 후속 조치 및 익일 확인 항목

분석 엑셀

  • Overview
  • Defect_Pareto
  • Equipment_NG_Rate
  • Time_Heatmap
  • Profile_Anomaly
  • Alarm_Link
  • Quantity_Validation
  • Evidence_Log

ID 수용 기준

AC-06AI 원인 후보마다 근거 데이터와 High/Medium/Low 신뢰도가 표시된다.
