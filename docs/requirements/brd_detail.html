1. 과제 개요

과제명

일일 설비/불량 현황 보고서 자동 작성

대상 공정

MODULE-A / Laminator

기준 시간

07시-익일 07시

핵심 목표

불량 감소, 원인 파악

2. 현재 업무 문제

현재 업무는 반복성과 데이터 확인 부담이 크고, 이슈가 발생하면 원인 추적이 늦어질 수 있다.

  • 수작업 집계 부담
    07-07 기준 생산량, 검사량, NG 수량, 불량률을 사람이 직접 필터링하고 집계한다.
  • 이상 징후 발견 지연
    LAM-03 14시대 CRACK 집중처럼 설비/시간대 패턴을 담당자가 직접 찾아야 한다.
  • 수량 불일치 위험
    재판정, 재투입, 데이터 누락으로 생산/검사/NG 수량이 맞지 않을 수 있다.
  • Profile 분석 어려움
    공정 time, 온도, 진공도 등 초 단위 설비 데이터에서 특이점을 찾기 어렵다.
  • 원인 추적 지연 손실
    동일 불량이 재발해도 설비 조건과 Recipe가 바뀌면 원인 추적이 어려워진다.
  • 보고 후 조치 연결 필요
    보고서가 설비 점검, Recipe 확인, 재발 모니터링으로 이어져야 한다.

3. 비즈니스 목표

목표 설명 업무 효과
CRACK/BUBBLE 우선 감소 최종 인터뷰에서 1, 2순위 감소 대상으로 선정 수율 개선과 재발 방지
원인 후보 조기 도출 불량 집중, Profile, 알람, 수량 검증을 함께 분석 원인 파악 리드타임 단축
팀장 보고 품질 향상 HTML 대시보드와 분석 엑셀로 근거 중심 보고 후속 조치 판단 속도 향상

4. 비즈니스 범위

포함 범위

  • 07-07 기준 생산/불량 데이터 분석
  • 불량 Pareto, 설비별/시간대별 집중 분석
  • 공정 time, 온도, 진공도 Profile 이상 확인
  • 설비 알람과 불량 집중 시간 연계
  • 팀장 보고용 HTML 및 분석 엑셀 생성

제외 범위

  • 원본 설비 데이터 외부 클라우드 전송
  • AI의 원인 확정 단정
  • 설비 제어값 자동 변경
  • 초기 MVP 단계의 검사 이미지 딥러닝 자동 판정

5. KPI 및 성과 측정

구분 KPI 측정 관점
정량 CRACK/BUBBLE 불량 감소율 우선 관리 불량의 발생 건수 변화
정량 동일 불량 재발 건수 감소 동일 설비/동일 시간대 재발 여부
정량 원인 후보 도출 리드타임 이슈 발생 후 근거 기반 후보 제시까지 시간
품질 보고 누락 감소 수량 불일치, 알람, Profile 이상 누락 여부
품질 후속 조치 연결률 보고 후 설비 점검, Recipe 확인, 재발 모니터링 수행 여부

6. 이상 징후 판단 방향

  • P1 동일 설비에서 동일 불량이 1시간 내 5건 이상 발생
  • P1 공정 time, 온도, 진공도 이상이 NG 집중 시간과 겹침
  • P2 설비 알람 발생 전후 30분 이내 동일 불량 연속 발생
  • P2 특정 설비의 시간당 불량률이 전체 평균의 2배 이상 증가
  • P3 재판정/재투입 이력과 수량 불일치가 동시에 발생

7. 리스크와 대응

리스크 영향 대응 방향
데이터 양식 변경 자동 집계 오류 컬럼 매핑 검증 단계 추가
이상 기준 과다 탐지 알람 피로도 증가 P1/P2/P3 우선순위 표시
AI 원인 후보 과신 잘못된 조치 가능 담당자 최종 승인과 근거 표시
보안 제약 데이터 활용 제한 라인 PC/사내망 PC 실행, 비식별 샘플 사용

8. 성공 기준

  • 07-07 기준 NG 수량, 불량 종류, 불량률이 정확히 집계된다.
  • CRACK/BUBBLE 불량 집중 설비와 시간대를 자동 탐지한다.
  • 공정 time, 온도, 진공도 이상과 불량 집중 시간의 연관성을 표시한다.
  • 팀장 보고용 HTML과 분석 엑셀을 출력한다.
  • 보고 후 설비 점검, Recipe 확인, 동일 불량 재발 모니터링으로 이어진다.
