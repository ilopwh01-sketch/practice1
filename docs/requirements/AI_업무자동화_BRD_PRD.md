# AI 업무 자동화 과제: 일일 설비/불량 현황 보고서 자동 작성

## 1. 과제 개요

본 과제는 모듈공정기술 업무 중 반복적으로 수행되는 일일 불량 이슈 확인, 검사 이미지 모니터링, 설비 Profile 특이점 확인, 불량 집중성 분석 업무를 AI로 자동화하는 방안을 정의한다.

인터뷰 결과, Laminator 공정에서는 매일 07시부터 익일 07시까지의 생산량, 불량 수량, 설비 이상, 검사 NG 이미지, 시간대별 불량 집중 여부를 확인해야 한다. 이 과정은 데이터 확인과 보고서 작성에 많은 시간이 소요되고, 수작업 특성상 누락 또는 오류 위험이 존재한다.

이에 따라 1순위 추진 과제로 **일일 설비/불량 현황 보고서 자동 작성**을 선정하였다.

## 2. BRD: Business Requirements Document

### 2.1 인터뷰 대상

- 대상: MJ
- 역할: 모듈공정기술
- 담당 라인/공정: Laminator
- 회사 KPI 관점: 수율 개선, 택타임 개선, 생산성 향상, 특허 아이디어 발굴

### 2.2 현재 업무

현재 담당자는 매일 생산 이후 발생한 불량 이슈를 확인하고, EL/AOI 검사 이미지를 기반으로 불량 상태를 분석한다. 또한 설비, 시간, 작업 조건 등 다양한 관점에서 불량 집중성을 확인하고, 4M 관점으로 원인 후보를 검토한다.

주요 업무는 다음과 같다.

- 일일 불량 이슈 확인
- EL/AOI 불량 검사 이미지 분석
- 설비별, 시간대별 불량 집중성 분석
- Laminator 설비 Profile 특이점 확인
- 4M 기준 원인 후보 분석
- 팀장 및 공정팀원 대상 보고 자료 작성

### 2.3 문제 정의

현재 업무의 가장 큰 문제는 데이터 확인과 보고서 작성이 반복적이고 수작업 의존도가 높다는 점이다.

매일 07시부터 익일 07시까지의 생산 데이터를 기준으로 불량 수율을 파악해야 하며, 특정 설비나 특정 시간대에 불량이 집중되는 경우 담당자가 직접 데이터를 확인해 이상 징후를 찾아야 한다.

예를 들어 Laminator 3호기에서 크랙 불량 10매가 특정 시간대에 집중 발생한 경우, 현재는 담당자가 직접 데이터를 확인하면서 해당 패턴을 발견해야 한다. 또한 재판정, 재투입, 데이터 집계 오류 등으로 인해 생산 수량과 불량 수량이 맞지 않는 경우가 발생할 수 있다.

설비 Profile 데이터는 초 단위로 기록되어 컬럼 수와 데이터 양이 많기 때문에, 특이점을 사람이 직접 확인하는 데 시간이 오래 걸린다.

### 2.4 Pain Point

- 매일 반복되는 생산량 및 불량 수율 집계
- 설비별, 시간대별 불량 집중 여부 수작업 확인
- Laminator 설비 Profile 특이점 수작업 확인
- 검사 NG 이미지 모니터링 부담
- 재판정 및 재투입으로 인한 수량 불일치 확인 어려움
- 보고서 작성 시 누락 및 표현 편차 발생
- 과검 및 불량 이미지 학습의 어려움

### 2.5 비즈니스 목표

AI 기반 자동화 도구를 활용하여 07시-07시 기준 불량 현황과 설비 이상 징후를 빠르게 파악하고, 불량 원인 후보를 조기에 도출할 수 있도록 한다.

보고서 작성 시간 단축은 부가 효과로 보되, 본 과제의 핵심 목표는 **불량 감소, 원인 파악 리드타임 단축, 설비/시간대별 이상 징후 조기 발견**으로 설정한다.

### 2.6 기대 효과

- 보고서 작성 시간 단축
- 수작업 집계 시간 감소
- 반복 오류 및 보고 누락 감소
- 설비/시간대별 불량 집중 구간 조기 발견
- 불량 원인 후보 도출 리드타임 단축
- 팀장 및 공정팀원의 의사결정 속도 향상
- 향후 특허 또는 현장 개선 아이디어 발굴 가능성 확대

### 2.7 KPI 연결

정량 KPI는 다음과 같이 설정한다.

- 월간 자동화 처리 건수
- 주요 불량 감소 건수 또는 감소율
- 동일 불량 재발 건수 감소
- 원인 후보 도출 리드타임 단축
- 생산 수량 및 불량 수량 불일치 탐지 건수
- 설비/시간대별 이상 징후 탐지 건수

품질 KPI는 다음과 같이 설정한다.

- 불량/알람 원인 후보 도출 리드타임 단축
- 보고 누락 감소
- 이슈 대응 속도 향상
- 설비 이상 징후 조기 발견 건수
- 팀장 보고 후 후속 조치 연결률

### 2.8 2차 인터뷰 반영 사항

2차 인터뷰 결과, 보고서 작성 시간은 평상시 약 30분, 이슈 발생 시 약 90분으로 확인되었다. 다만 사용자가 중요하게 보는 성공 기준은 단순 시간 절감이 아니라 **불량 감소와 원인 파악**이다.

따라서 본 과제는 보고 자동화 과제이지만, 성과 평가는 작성 시간보다 다음 항목을 중심으로 한다.

- 07시-07시 기준 데이터 정확도
- NG 수량 및 불량 종류 집계 정확도
- 불량률 계산 정확도
- 불량 집중 설비/시간대 조기 발견
- 공정 time, 온도, 진공도 기반 원인 후보 도출
- 팀장 보고용 HTML 및 데이터 분석 엑셀 출력

## 3. PRD: Product Requirements Document

### 3.1 제품명

AI 일일 설비/불량 현황 보고서 자동 작성 도구

### 3.2 사용자

- 모듈공정기술 담당자
- 공정팀원
- 팀장

### 3.3 핵심 기능

#### 기능 1. 엑셀/CSV 데이터 업로드 및 분석

사용자는 라인 PC 또는 사내 시스템에서 다운로드한 설비 알람 CSV, 생산 실적 엑셀, 불량 데이터 엑셀을 입력한다. AI 도구는 입력 데이터를 기준으로 생산량, 불량 수량, 불량률, 설비별 불량 현황을 자동 집계한다.

#### 기능 2. 07시-07시 기준 일일 현황 자동 집계

현장 기준에 맞게 07시부터 익일 07시까지의 데이터를 일일 기준으로 분리한다. 이를 통해 실제 업무 기준과 동일한 단위로 보고서를 생성한다.

#### 기능 3. 불량 Pareto 자동 정리

발생 빈도가 높은 불량 유형을 자동으로 정렬하고, 상위 불량 항목을 Pareto 형태로 요약한다. 예를 들어 크랙, 미접착, 외관 NG 등 불량 유형별 발생 건수와 비율을 자동 산출한다.

#### 기능 4. 설비별/시간대별 집중성 분석

특정 설비 또는 특정 시간대에 불량이 집중되는지 자동으로 탐지한다.

이상 징후 기준은 다음과 같이 설정한다.

- 동일 설비에서 동일 불량이 1시간 내 5건 이상 발생
- 특정 설비의 시간당 불량률이 전체 평균의 2배 이상 증가
- 특정 시간대 NG 수량이 직전 3시간 평균 대비 3배 이상 증가
- 특정 불량 코드가 일일 전체 NG의 40% 이상을 차지
- 설비 알람 발생 전후 30분 이내 동일 불량이 연속 발생
- 재판정 또는 재투입 이력과 수량 불일치가 동시에 발생

#### 기능 5. 설비 Profile 특이점 탐지

초 단위로 기록되는 설비 Profile 데이터에서 이상 패턴을 탐지한다. 1차 분석 대상 컬럼은 **공정 time, 온도, 진공도**로 설정한다.

Profile 이상 징후 기준은 다음과 같이 설정한다.

- 공정 time이 기준값 또는 최근 평균 대비 10% 이상 증가
- 온도가 관리 기준 상한/하한을 벗어나거나, 동일 구간에서 급격히 변동
- 진공도가 기준 범위에서 벗어나거나, 불량 집중 시간대에 동시 하락
- Profile 이상 발생 시간과 NG 집중 시간의 차이가 30분 이내
- Profile 이상, 설비 알람, 동일 불량 집중이 동시에 발생

#### 기능 6. 수량 불일치 탐지

생산 수량, 검사 수량, 불량 수량 간 불일치 여부를 확인한다. 재판정, 재투입, 데이터 누락 등으로 인해 수량이 맞지 않는 경우 자동으로 경고한다.

예시:

- 실제 생산 4,000매, 불량 10매
- 데이터상 생산 3,900매, 불량 9매
- 결과: 수량 불일치 발생, 재판정/재투입 이력 확인 필요

#### 기능 7. 일일 보고서 자동 작성

분석 결과를 기반으로 팀장 및 공정팀원이 바로 확인할 수 있는 보고서 초안을 자동 생성한다.

보고서 구성은 다음과 같다.

- 금일 생산 현황
- 금일 불량 현황
- 주요 불량 Pareto
- 설비별 특이 사항
- 시간대별 집중 발생 이슈
- 수량 불일치 여부
- 원인 후보
- 조치 필요 사항
- 익일 확인 항목

#### 기능 8. 수기 메모 요약

담당자가 작성한 수기 메모나 회의 내용을 입력하면 AI가 핵심 내용을 요약하고, 보고서의 이슈 및 조치 항목에 반영한다.

### 3.4 입력 데이터

- 설비 알람 CSV
- 생산 실적 엑셀
- DB에서 추출한 엑셀
- 불량 검사 결과 엑셀
- EL/AOI 검사 NG 이미지 정보
- 담당자 수기 메모

### 3.5 출력 결과

- 팀장 보고용 HTML 보고서
- 데이터 분석용 엑셀 요약 파일
- 불량 Pareto 요약
- 설비별 이상 징후 요약
- 시간대별 불량 집중 분석
- 수량 불일치 경고 목록
- 원인 후보 및 조치 필요 사항

### 3.6 보안 조건

현장 설비 원본 데이터는 외부로 반출하지 않는다. 자동화 도구는 사내 인트라넷 또는 로컬 PC 환경에서 처리하는 것을 원칙으로 한다.

과제 또는 테스트 목적의 데이터는 민감 정보를 제거한 비식별 샘플 데이터만 사용한다.

### 3.7 성공 기준

본 자동화 과제의 성공 기준은 다음과 같다.

- 07시-07시 기준 NG 수량, 불량 종류, 불량률이 정확히 집계됨
- 설비별/시간대별 불량 집중 이슈 자동 탐지 가능
- 생산 수량 및 불량 수량 불일치 자동 표시 가능
- 공정 time, 온도, 진공도 이상과 불량 집중 시간의 연관성 표시 가능
- 팀장 보고용 HTML과 분석 엑셀을 동시에 출력 가능
- 자동화 결과가 실제 불량 감소 또는 원인 파악에 기여함

## 5. 첫 실행 계획

1. 현재 사용 중인 보고서 및 엑셀 양식을 수집한다.
2. 민감 정보를 제거한 샘플 데이터를 준비한다.
3. 자동 분류 규칙과 보고서 출력 양식을 정의한다.
4. 1주일간 기존 방식과 자동화 방식을 병행한다.
5. 불량 집중 탐지, 원인 후보 도출, 수량 불일치 탐지 효과를 측정한다.
6. KPI 근거를 바탕으로 확대 적용 가능성을 검토한다.

## 6. 결론

Laminator 공정의 일일 설비/불량 현황 보고서는 반복성이 높고, 데이터 기반 판단이 중요하며, 수율 개선 KPI에 직접 연결되는 업무이다.

AI를 활용하면 생산량, 불량률, 설비별 이상 징후, 시간대별 집중 발생 이슈를 자동으로 정리할 수 있다. 특히 공정 time, 온도, 진공도와 같은 Profile 데이터를 불량 집중 시간과 함께 확인하면 원인 후보를 더 빠르게 좁힐 수 있다.

따라서 본 과제의 1순위 자동화 대상으로 **일일 설비/불량 현황 보고서 자동 작성**을 선정하는 것이 적절하다. 단, 성과 평가는 단순 보고서 작성 시간 절감보다 **불량 감소와 원인 파악 정확도**를 중심으로 측정해야 한다.
