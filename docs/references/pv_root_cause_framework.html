PV 모듈 불량 원인분석 프레임워크

태양광 모듈 Failure Mode 논문을 기반으로 CRACK, BUBBLE/DELAMINATION, INACTIVE AREA를 현장 데이터와 연결해 분석하는 방법입니다.

1. 분석 원칙

전문적인 RCA는 한 개의 숫자로 원인을 단정하지 않고, 문헌 기반 Failure Mode와 현장 데이터를 묶어 경쟁 가설을 좁혀갑니다.

현상 정의불량 코드, EL pattern, 설비, 시간대를 먼저 고정한다.
문헌 매핑PV Failure Mode별 일반 원인 후보를 연결한다.
공정 근거Profile, 알람, Recipe, 재투입 이력을 확인한다.
경쟁 가설가능 원인과 배제해야 할 원인을 같이 둔다.
검증 조치추가 데이터와 현장 점검으로 확정한다.

Cell crack EL dark line, cross crack, edge crack, inactive area. Crack pattern은 제조/취급/기계적 스트레스와 함께 해석. Handling stress, stringing/tabbing stress, lamination pressure imbalance, pre-existing cell micro-crack propagation. EL 원본/전처리 이미지, crack 위치, module sequence, lamination pressure/cycle, upstream handling log, pre-lamination EL. 동일 설비/시간대 재발 확인, 진공/압력 균일성 점검, upstream 공정 이력 대조.
Bubble / Delamination Encapsulant void, interfacial separation, blister/bubble. 계면 접착, 수분, 온도, 진공, 압력과 함께 검토. Insufficient vacuum, lamination temperature/time window deviation, trapped moisture, contamination, encapsulant adhesion issue. vacuum_kpa, lamination_temp_c, pressure, cooling_time, visual_bubble_count, encapsulant lot, storage humidity. Vacuum pump/seal 점검, Recipe window 확인, EVA/Lot 및 보관 조건 확인, bubble 위치 지도화.

3. LAM-03 14시대 CRACK 사례 전문 분석

샘플 대시보드의 “LAM-03 14시대 CRACK 집중”을 논문 기반 RCA 방식으로 다시 해석한 결과입니다.

1차 원인 후보

  • Primary Lamination vacuum/pressure process window disturbance
    근거: CRACK 시간 집중, vacuum drop, pressure alarm, cycle time 증가가 같은 구간에 발생.
  • Secondary Pre-existing cell micro-crack propagation
    근거: 논문상 micro-crack은 lamination/handling stress에서 확장될 수 있음. 단, pre-lamination EL이 없으면 확정 불가.
  • Secondary Upper heater/thermal gradient contribution
    근거: 상부 온도 상승과 heater deviation 알람이 겹치나, CRACK 직접 원인으로 보려면 위치/패턴 검증 필요.

경쟁 가설과 배제 조건

  • Handling 단독 원인
    여러 설비/시간대에 분산 발생하면 가능성이 높고, LAM-03 14시대에만 집중되면 단독 원인 가능성은 낮아짐.
  • EL 판정 편차
    특정 검사기/검사관에서만 급증하면 검사 조건을 확인해야 함. 동일 시간대 LAM-03 설비 연계가 강하면 공정 원인 가능성이 커짐.
  • 장기 열화/PID
    일일 생산 직후 특정 설비/시간대 집중과는 성격이 다르므로 본 이슈의 1차 원인으로 보기는 어려움.

4. 전문 RCA 점수화 기준

AI 원인 후보는 점수화하되, 최종 확정은 담당자가 승인합니다.

근거 항목 점수 설명
동일 설비/동일 시간대 집중 +2 설비 또는 시간대 특정성이 강할수록 공정 원인 가능성이 증가.
Failure Mode와 논문 관찰 포인트 일치 +2 EL crack pattern, bubble location, inactive area 등 문헌 기반 패턴과 맞는 경우.
Profile 이상 동시 발생 +2 진공도, 온도, 압력, cycle time 이상이 불량 집중 시간과 겹침.
설비 알람 동시 발생 +1 알람 전후 30분 내 불량 집중이 있으면 보조 근거.
대체 가설 배제 +1 검사기 편차, upstream handling, 장기 열화 가능성을 비교해 낮아진 경우.
수량 불일치/재투입 존재 -1 데이터 신뢰성 검증 전까지 원인 후보 신뢰도를 낮춤.

5. 샘플 사례 결론 문장

LAM-03 14시대 CRACK 집중은 단순한 불량 건수 증가가 아니라, EL 기반 cell crack Failure Mode와 라미네이션 공정 Profile 이상이 시간적으로 겹친 케이스이다. 현재 근거만으로 원인을 확정할 수는 없지만, vacuum/pressure process window disturbance를 1차 원인 후보로 두고, pre-existing micro-crack propagation과 upper heater/thermal gradient를 경쟁 가설로 검증하는 것이 타당하다. 다음 조치는 진공 펌프/Seal, 압력 균일성, Recipe 변경 이력, pre-lamination EL 또는 upstream handling log 확인이다.
