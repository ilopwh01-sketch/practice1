보고서 작성 시간

평상시 30분, 이슈 발생 시 90분

필수 검증 숫자

07-07시 기준, NG 수량/종류, 불량률

핵심 Profile 컬럼

공정 time, 온도, 진공도

출력 형태

성공 기준

불량 감소, 원인 파악 정확도

과제 방향

보고 자동화에서 원인 후보 도출 자동화로 확장

제안 이상 징후 기준

  • 동일 설비/동일 불량 집중
    동일 설비에서 같은 불량 코드가 1시간 내 5건 이상 발생하면 이상 징후로 표시한다.
  • 설비별 불량률 급증
    특정 설비의 시간당 불량률이 전체 평균의 2배 이상이면 설비 집중 이슈로 표시한다.
  • 시간대별 NG 급증
    특정 시간대 NG 수량이 직전 3시간 평균 대비 3배 이상 증가하면 시간 집중 이슈로 표시한다.
  • 불량 Pareto 쏠림
    특정 불량 코드가 일일 전체 NG의 40% 이상을 차지하면 주요 불량 이슈로 표시한다.
  • 설비 알람 연계
    설비 알람 발생 전후 30분 이내 동일 불량이 연속 발생하면 알람 연계 원인 후보로 표시한다.
  • Profile 동시 이탈
    공정 time 증가, 온도 급변, 진공도 하락이 NG 집중 시간과 겹치면 Profile 원인 후보로 표시한다.
  • 수량 불일치
    생산량, 검사량, NG 수량이 맞지 않고 재판정/재투입 이력이 있으면 데이터 검증 필요 항목으로 표시한다.

BRD/PRD 반영 방향

BRD 관점
이 과제는 단순히 보고 시간을 줄이는 자동화가 아니라, 불량 원인 후보를 빠르게 좁혀 수율 개선에 기여하는 업무 자동화로 정의한다.
PRD 관점
MVP는 07-07 기준 집계, 불량 집중 탐지, Profile 이상 연계, 팀장 보고용 HTML, 분석 엑셀 출력까지 포함한다.
