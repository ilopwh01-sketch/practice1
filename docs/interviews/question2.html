Laminator 공정의 일일 설비/불량 보고 자동화를 더 구체화하기 위한 질문

아래 질문은 인터뷰 요약과 BRD/PRD 초안을 바탕으로 만들었습니다. 답변을 채우면 자동화 대상, 입력 데이터, 출력 보고서, KPI 검증 방식이 더 명확해집니다.

핵심 키워드

07시-07시 기준 Laminator 불량 Pareto 설비 Profile 수량 불일치 로컬 처리 보고 자동화

1. BRD 보완 질문

비즈니스 관점에서 왜 이 과제가 필요한지, 어떤 의사결정에 쓰이는지 확인하는 질문입니다.

현재 일일 설비/불량 현황 보고서를 작성하는 데 평균 몇 분 또는 몇 시간이 걸리나요? 시간 절감 KPI를 계산하기 위한 기준값입니다.
팀장님과 공정팀원이 보고서에서 가장 먼저 확인하는 항목은 무엇인가요? 보고서 자동 생성 시 우선순위를 정하기 위한 질문입니다.
이 보고서가 실제로 어떤 조치나 의사결정으로 이어지나요? AI 자동화의 비즈니스 효과를 설명하는 근거가 됩니다.
현재 가장 자주 놓치는 이슈는 설비 이상, 불량 집중, 수량 불일치 중 무엇인가요? 자동화 기능의 우선순위를 정하는 데 사용합니다.

2. PRD 보완 질문

제품 기능 관점에서 어떤 입력을 받고 어떤 결과물을 내야 하는지 구체화하는 질문입니다.

자동 보고서에 반드시 포함되어야 하는 표 또는 그래프는 무엇인가요? 예: 불량 Pareto, 설비별 불량률, 시간대별 추이, 수량 불일치 표.
AI가 이상 징후로 판단해야 하는 기준은 어떻게 잡는 것이 좋나요? 규칙 기반 자동화의 기준값을 정하는 질문입니다.
설비 Profile에서 가장 중요하게 보는 컬럼은 무엇인가요? 데이터 컬럼이 많을 때 우선 분석 대상을 좁히기 위한 질문입니다.
자동 생성된 보고서는 어떤 형태가 가장 사용하기 편한가요? 엑셀, HTML, PDF, 메일 본문 등 현장에서 바로 쓰기 좋은 출력 형태를 고릅니다.

3. 데이터/보안 확인 질문

외부 반출 금지 조건을 지키면서 로컬 자동화를 설계하기 위한 질문입니다.

현재 내려받을 수 있는 파일의 이름과 컬럼 구조는 어느 정도 고정되어 있나요? 파일 기반 자동화가 안정적으로 작동할 수 있는지 확인합니다.
비식별 처리 후에도 과제 샘플로 사용할 수 없는 민감 항목은 무엇인가요? 보안 제약을 먼저 정리해야 과제 설계가 안전해집니다.
수량 불일치가 발생했을 때 확인해야 하는 이력 데이터는 어디에 있나요? 재판정, 재투입, 검사 재처리 데이터를 연결할 수 있는지 확인합니다.

4. KPI 검증 질문

자동화 결과를 과제 성과로 설명하기 위한 측정 질문입니다.

시간 절감

기존 작성 시간과 자동화 후 검토 시간을 비교할 수 있나요?

오류 감소

수량 불일치, 보고 누락, 복사/붙여넣기 오류를 기록할 수 있나요?

이슈 대응

불량 집중 또는 설비 이상을 발견하는 시간이 줄어드는지 볼 수 있나요?

확장성

Laminator 외 다른 공정에도 같은 양식을 적용할 수 있나요?

5. AI에게 바로 물어볼 질문 프롬프트

아래 문장을 복사해서 AI에게 주면, 답변을 기반으로 BRD/PRD를 더 다듬을 수 있습니다.

다음은 Laminator 공정의 AI 업무 자동화 과제입니다.

과제명: 일일 설비/불량 현황 보고서 자동 작성
대상 업무: 07시-07시 기준 생산량, 불량 수율, 설비 Profile, 검사 NG 이미지, 시간대별 불량 집중성 확인
핵심 Pain Point: 수작업 집계, 이상 징후 누락, 수량 불일치, 보고서 작성 시간 소요
사용 데이터: 설비 알람 CSV, 생산 실적 엑셀, DB 추출 엑셀, 수기 메모
보안 조건: 원본 데이터 외부 반출 금지, 로컬 PC 또는 비식별 샘플 데이터 활용
