최종 추가 인터뷰

BRD/PRD 작성 전 한 번에 확인할 질문

이미 답변된 내용은 제외하고, 문서를 더 실제 업무처럼 보이게 만드는 데 필요한 항목만 모았습니다.

과제 일일 설비/불량 현황 보고서 자동 작성
핵심 목표 불량 감소, 원인 파악
출력 팀장 보고용 HTML + 분석 엑셀
중요 컬럼 공정 time, 온도, 진공도

1. BRD 보강 질문

BRD는 기능 설명보다 비즈니스 문제, 영향, 성공 기준을 분명히 쓰는 문서입니다.

이 과제가 해결되면 가장 직접적으로 줄이고 싶은 불량은 무엇인가요?

예: CRACK, BUBBLE, EDGE, FOREIGN 중 우선순위를 정합니다.

원인 파악이 늦어졌을 때 현장에서 생기는 손실은 무엇인가요?

BRD의 문제 심각도와 기대효과를 설명하는 근거가 됩니다.

팀장님 보고 후 실제로 이어져야 하는 후속 조치는 무엇인가요?

보고서가 단순 공유가 아니라 의사결정으로 이어지는 흐름을 정의합니다.

2. PRD 보강 질문

PRD는 사용자가 어떤 화면에서 무엇을 입력하고, 어떤 결과를 받는지 구체적으로 쓰는 문서입니다.

분석 엑셀에는 어떤 시트가 있으면 좋나요?

HTML 보고서와 별개로 실무자가 데이터를 다시 확인할 수 있는 구조를 정합니다.

팀장 보고용 HTML 첫 화면에서 가장 위에 보여야 할 3가지는 무엇인가요?

화면 우선순위를 결정합니다.

AI가 원인 후보를 제안할 때 표시해야 할 신뢰도나 근거는 어떤 방식이 좋나요?

AI 결과를 사람이 검증하기 쉽게 만드는 요구사항입니다.

3. 운영/보안 보강 질문

현장 적용 가능성과 보안 조건을 문서에 명확히 쓰기 위한 질문입니다.

자동화 도구는 어디에서 실행되는 것이 가장 현실적인가요?

로컬 PC, 라인 PC, 사내 서버, 엑셀 매크로 형태 중 현실적인 방식을 적습니다.

사람이 최종 승인해야 하는 항목은 무엇인가요?

AI가 자동으로 결론을 확정하지 않고, 담당자가 검증하는 경계를 정합니다.
