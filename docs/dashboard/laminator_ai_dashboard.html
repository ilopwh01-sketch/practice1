    5. AI 원인 후보와 근거

    논문 기반 원칙에 따라 AI 결론은 확정이 아니라 근거와 신뢰도를 가진 원인 후보로 표시한다. 상세한 경쟁 가설과 점수화 기준은 전문 RCA 프레임워크를 기준으로 한다.

    후보 1. Lamination vacuum/pressure process window disturbance

    High
    • 불량 집중: LAM-03 14:00-15:00 CRACK 10건
    • 설비 알람: 13:58 ALM-301 Vacuum pressure deviation, 14:06 ALM-304 Press pressure fluctuation
    • Profile: vacuum_kpa -96.2에서 -89.1까지 하락, cycle_time_sec 92.4에서 99.0까지 증가
    • 전문 해석: EL 기반 Cell crack Failure Mode가 특정 설비/시간대와 공정 Profile 이상에 동시에 연결되어 1차 공정 원인 후보로 판단

    후보 2. Pre-existing micro-crack propagation 또는 thermal gradient 기여

    Medium
    • Profile: upper_temp_c 146.5에서 150.2까지 상승
    • 설비 알람: 14:29 ALM-208 Upper heater deviation
    • 경쟁 가설: 이미 존재하던 micro-crack이 라미네이션 스트레스에서 확장되었을 가능성
    • 검증 필요: pre-lamination EL, upstream handling/stringing log, crack 위치가 edge/cross/inactive area 중 어디인지 확인

    후보 3. 재판정/재투입으로 인한 수량 검증 필요

    Low
    • LAM-03 14시대 output 187, inspection 186으로 1매 차이
    • 재판정 1건, 재투입 2건 이력 존재
    • 불량 원인보다는 데이터 검증 필요 항목으로 분리 관리

    후보 4. PV 모듈 Failure Mode 관점의 Bubble/Delamination 리스크

    Medium
    • 문헌 매핑: Bubble/Delamination은 Encapsulant void, 접착 저하, 수분/온도/진공 조건과 함께 검토
    • 현장 데이터: LAM-03 14시대 진공도 하락과 온도 상승이 함께 나타남
    • 확인 필요: Visual bubble count, 냉각 시간, Encapsulant Lot, Recipe 변경 이력

    배제/분리해야 할 가설. 장기 열화/PID 또는 검사 편차

    Low
    • 장기 열화/PID는 특정 설비 1시간 구간 집중보다 현장 사용 환경, 습도, 전압, 장기 노출과 더 관련이 큼
    • 검사기/검사관 편차는 동일 시간대 다른 설비에서도 유사하게 증가하는지 확인해야 함
    • 현재 샘플에서는 LAM-03 14시대에 집중되어 공정/설비 원인 후보가 더 우선

    8. 논문 기반 설계 근거

    대시보드의 AI 원인 후보 표시 방식은 제조 RCA/이상탐지 논문에서 공통적으로 강조하는 설명가능성, 다중 데이터 결합, 전문가 검증 원칙을 반영했다. 논문별 설명 이미지는 논문 레퍼런스 화면에서 확인한다.

    논문 근거 대시보드 반영
    Calaon et al., 2024: 제조 RCA에서 다중 데이터와 XAI 결합을 제안 불량 이벤트, Profile, 알람, 수량 검증을 한 원인 후보에 묶어 표시
    IEA PVPS Task 13: PV 모듈 Failure Mode와 EL 검사에서 Crack/Inactive area 식별 기준 정리 EL dark line, inactive area, 반복 crack pattern을 CRACK 원인 후보 근거로 사용
    Deitsch et al., 2019: EL 이미지 수동 분석은 시간과 전문성이 많이 필요하며 자동 분류가 가능함 EL 이미지 판단을 AI 보조 분석 대상으로 두고, 최종 확정은 담당자 승인으로 분리
    PV Delamination Review: 계면 박리와 Encapsulant/Backsheet/Cell 계면 문제 정리 Bubble/Delamination 후보를 진공도, 온도, 압력, 냉각 시간 데이터와 연결
    Choi et al., 2022: 이상 탐지 결과에 센서 영향도/원인 설명 필요 진공도, 온도, 공정 time을 근거 데이터로 표시하고 신뢰도 부여
    Wehner et al., 2024: 제조 RCA에서 전문가 지식과 데이터 기반 모델의 피드백 루프 강조 AI 결론을 확정하지 않고 담당자 최종 승인 항목을 분리
    Allen et al., 2024: 도메인 지식 기반 시공간 분석으로 이상 원인을 설명 불량 집중 시간과 Profile/알람 타임라인을 함께 시각화
