5. AI 원인 후보 분석

논문 기반 Failure Mode + 현장 데이터 + 경쟁 가설 방식으로 원인 후보를 제시합니다.

분석 원칙: AI는 “원인 확정”이 아니라 문헌에서 알려진 Failure Mode를 현장 데이터 신호와 매칭해 검증 우선순위를 제안합니다. CRACK은 EL pattern과 공정 stress를 함께 보고, BUBBLE/Delamination은 encapsulant 계면, 진공, 온도, 압력 조건을 함께 확인합니다.

1차 후보: Vacuum / Pressure Process Window Disturbance

High
  • 현장 신호: CRACK이 LAM-03 14시대에 10건 집중되고, 동일 시간대 vacuum_kpa 하락과 pressure fluctuation 알람이 겹침
  • 문헌 연결: PV Failure review와 EL 관찰 문헌은 crack/inactive area를 단순 불량명이 아니라 mechanical/process stress와 함께 해석할 것을 제안
  • 판단: defect concentration + profile anomaly + alarm overlap + 반복 recipe 이력까지 4개 근거가 맞물려 High 후보로 표시

경쟁 가설: Pre-existing Micro-crack Propagation

Medium
  • 현장 신호: CRACK이 특정 설비에서 집중됐지만, crack이 라미네이션 이전에 이미 존재했는지는 아직 미확인
  • 문헌 연결: EL image 분류 연구는 crack pattern, inactive area, cell 단위 defect probability를 분리해 봐야 함을 보여줌
  • 검증 조건: Pre-lamination EL, stringing/handling log, rework 이력이 연결되면 1차 후보와 경쟁 가설의 우선순위를 재계산

별도 후보: Bubble / Delamination Process Sensitivity

Medium
  • 현장 신호: BUBBLE은 금일 Top defect는 아니지만 BOM-A/RCP-A1 조건에서 전주 대비 증가
  • 문헌 연결: Delamination/Blistering 문헌은 encapsulant 계면, void, 수분, 온도, 압력 조건을 함께 확인하도록 설명
  • 검증 조건: visual bubble count, cooling time, encapsulant lot, 진공 유지 시간 데이터를 추가하면 CRACK 분석과 별도 트랙으로 관리

6. 논문 기반 분석 근거

아래 표는 논문/리뷰 내용을 그대로 복사하는 것이 아니라, 현장 대시보드에서 사용할 판단 기준으로 변환한 예시입니다.

문헌/자료 전문 분석 관점 필요 데이터 대시보드 적용
IEA PVPS Task 13 Failure Review Crack, inactive area, delamination 등 Failure Mode를 분리해 보고, 관찰 현상과 가능한 stress 요인을 연결 defect_code, EL pattern, equipment_id, profile anomaly, alarm time “CRACK 집중”을 단순 수량이 아니라 공정 stress 후보와 함께 표시
EPJ Photovoltaics EL Nomenclature EL 관찰 항목은 이름과 위치를 표준화해야 비교 가능하므로 defect_code와 pattern_hint를 분리 EL image_ref, crack location, inactive area 여부, cell position 검사 이미지를 “CRACK” 하나로 묶지 않고 edge/cross/inactive pattern으로 세분화
Deitsch et al. EL Defect Classification EL 이미지는 수동 판정 편차와 시간 부담이 있어 AI 보조 분류의 가치가 있음 EL image crop, cell-level defect probability, judge/rejudge result AI가 EL 원본을 바로 확정 판정하지 않고 “검사 확인 필요” 액션으로 연결
Interfacial Delamination Review Bubble/Delamination은 계면 위치와 encapsulant/backsheet/cell interface 관점으로 분류 visual_bubble_count, vacuum_kpa, temperature, pressure, cooling_time, material lot BUBBLE은 외관 수량만 보지 않고 진공/온도/압력 profile과 함께 별도 RCA 트랙으로 표시
보고 표현 기준: “논문상 가능 원인”과 “현장 데이터에서 확인된 신호”를 분리해 표시해 과잉 단정을 막습니다.
