4. 시각화 컴포넌트 기준

보고 화면은 장식보다 빠른 판단이 중요하다. 숫자, 비교, 집중 구간, 원인 후보 순서로 보여준다.

KPI 카드

총 생산량, 검사량, NG 수량, NG율, 이상 징후 수를 표시한다.

위험도 점수

불량 집중, 우선 관리 불량, Profile/알람 중첩, 수량 불일치를 100점 만점으로 환산해 첫 화면에 표시한다.

Pareto Bar

불량 코드별 발생 수량과 누적 비중을 표시한다.

Heatmap

설비 x 시간대 NG 집중도를 색상으로 표시한다.

Timeline

알람, Profile 이상, NG 집중 발생 순서를 연결한다.

RCA Evidence Matrix

논문 근거, 현장 데이터 신호, 원인 후보, 검증 액션을 표로 연결한다.

5. 논문 기반 RCA 화면 설계

이 영역은 발표 설득력을 높이는 핵심 화면이다. 논문을 단순 링크로 보여주지 않고, 현장 판단 기준으로 변환해 보여준다.

화면 항목 표시 내용 사용자가 확인할 질문
문헌 Failure Mode Crack, inactive area, Bubble/Delamination, interconnect issue 등 이 불량은 문헌상 어떤 유형으로 분류되는가?
현장 데이터 신호 설비/시간 집중, Profile 이상, 알람, BOM/Recipe 반복성 문헌에서 말하는 원인 후보와 현재 데이터가 실제로 겹치는가?
경쟁 가설 라미네이션 stress, 기존 micro-crack, 검사 편차, 자재 lot 민감도 지금 데이터만으로 배제할 수 없는 원인은 무엇인가?
검증 액션 EL 원본 확인, pre-lamination EL 확인, 설비 진공/압력 점검, Recipe 재확인 담당자가 다음으로 확인할 데이터나 조치는 무엇인가?

6. 이상 징후 표시 기준

이 기준은 2차 인터뷰에서 “잘 모르겠다”고 답한 항목을 분석적으로 제안한 것이다.

P1 동일 설비/동일 불량 집중

동일 설비에서 동일 불량이 1시간 내 5건 이상 발생하면 즉시 강조한다.

P1 Profile 동시 이탈

공정 time 증가, 온도 급변, 진공도 하락이 NG 집중 시간과 겹치면 원인 후보로 표시한다.

P2 설비 알람 연계

알람 전후 30분 이내 동일 불량이 연속 발생하면 알람 연계 이슈로 표시한다.

P2 평균 대비 급증

시간당 불량률이 전체 평균의 2배 이상이면 설비 집중 이슈로 표시한다.

P3 불량 Pareto 쏠림

특정 불량 코드가 일일 전체 NG의 40% 이상이면 주요 불량으로 표시한다.

P3 수량 불일치

생산량, 검사량, NG 수량이 맞지 않으면 재판정/재투입 이력 확인 대상으로 표시한다.

7. 데이터 컬럼 매핑

샘플 데이터 파일 기준으로 어떤 컬럼이 어떤 화면에 쓰이는지 정의한다.

컬럼 매핑 추천 패널

업로드 직후 원본 컬럼을 시간, 설비, 불량, 알람, Profile, 생산수량, BOM/Recipe, 기타 수치로 자동 분류하고 표준 컬럼명과 추천 신뢰도를 함께 표시한다. 신뢰도가 낮은 컬럼은 사람이 확인해야 할 항목으로 강조한다.

화면 영역 사용 파일 핵심 컬럼 표시 내용

8. MVP 화면 범위

처음부터 검사 이미지 AI 판정까지 넣기보다, 파일 기반 분석과 원인 후보 도출을 먼저 구현한다.

1차 구현

CSV/엑셀 업로드, 07-07 집계, KPI 카드, 불량 Pareto, 설비/시간 Heatmap.

2차 구현

공정 time, 온도, 진공도 Profile과 알람 이력을 불량 집중 시간과 연결.

3차 확장

EL/AOI 이미지 학습, 과검 패턴 분류, 유사 이미지 기반 불량 원인 추천.
