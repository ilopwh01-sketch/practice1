2. 주요 컬럼 사전

컬럼 파일 의미 대시보드 사용처
time_bucket daily_production_summary 07-07 기준 시간대 구간 시간 Heatmap
equipment_id 공통 LAM-01, LAM-02, LAM-03 등 설비 ID 설비별 NG율, 원인 후보
inspection_qty daily_production_summary 검사 완료 수량 불량률 계산 분모
ng_qty daily_production_summary NG 수량 KPI 카드, Heatmap
defect_code defect_events CRACK, BUBBLE, EDGE, FOREIGN 등 불량 코드 불량 Pareto, 우선 감소 대상
alarm_code equipment_alarm 설비 알람 코드 Profile/알람 Timeline
severity equipment_alarm 알람 심각도 LOW/MEDIUM/HIGH P1/P2 우선순위 판단
upper_temp_c laminator_profile_snapshot 상부 온도 Profile 이상 탐지
vacuum_kpa laminator_profile_snapshot 진공도 CRACK 원인 후보 근거
cycle_time_sec laminator_profile_snapshot 공정 time 또는 Cycle time 공정 time 이상 탐지

3. 의도된 이상 케이스

  • P1LAM-03 14시대 CRACK 집중
    동일 설비/동일 불량이 1시간 내 10건 발생하도록 구성했습니다.
  • P1Profile 동시 이탈
    14시대 진공도 하락, 압력 저하, 상부 온도 상승, 공정 time 증가가 나타나도록 구성했습니다.
  • P2설비 알람 연계
    13:58, 14:06에 LAM-03 HIGH 알람이 발생해 CRACK 집중 시간과 겹치도록 구성했습니다.
  • P2수량 불일치
    LAM-03 14시대 output_qty 187, inspection_qty 186으로 1매 차이가 발생하도록 구성했습니다.
  • 검증재판정/재투입 이력
    재판정 1건, 재투입 2건을 넣어 MES 재확인 필요 케이스를 만들었습니다.

4. 일반 PV 모듈 샘플 데이터

메모장 요청에 따라 실제 현장 데이터가 없어도 설명 가능한 일반 샘플 데이터를 추가했습니다. Failure Mode별 그림 설명은 논문 레퍼런스 화면과 연결됩니다.

파일 목적 포함 Failure Mode
general_module_daily_summary.csv 공정 단계별 NG 현황 요약 Cell crack, Bubble/Delamination, Low power
general_module_defect_events.csv 일반 불량 이벤트 단위 샘플 CRACK, BUBBLE, INACTIVE_AREA, DISCOLOR, PID_SUSPECT
general_module_process_context.csv 라미네이션 공정 조건 샘플 온도, 진공도, 압력, Cycle time, Bubble count
pv_failure_mode_reference.csv 논문 기반 Failure Mode 매핑 불량-검사방법-가능 원인-확인 데이터-권장 조치
