현장 데이터 요청서

AI 원인 분석용 CSV 데이터 요청 항목

CRACK/BUBBLE 불량에 대해 통계 분석, 설비 조건 연결, 문헌 기반 원인 후보 분석을 수행하기 위한 최소 데이터 항목입니다.

CSV Root Cause Statistics CRACK/BUBBLE

1. 요청 목적

AI 분석의 핵심은 단순히 불량 건수를 세는 것이 아니라, 불량 발생 데이터를 설비 Profile, 알람, BOM/Recipe, 불량 위치 정보와 연결해 왜 발생했을 가능성이 높은지 설명하는 것입니다.

가능한 분석

설비/시간 집중, 평균 대비 이상 여부, 표준편차, Boxplot, Pareto, 위험도 점수, 문헌 Failure Mode 연결.

주의사항

AI는 원인을 확정하지 않고 검증 우선순위를 제안합니다. 최종 조치와 Recipe 변경은 담당자가 승인해야 합니다.

2. 요청 파일 목록

우선순위 파일명 목적 핵심 컬럼
필수 defect_events.csv 불량 1건 단위 이벤트 분석 event_time, line, equipment_id, module_id, defect_code, defect_position
필수 production_summary.csv 불량률 계산을 위한 생산/검사 분모 work_date, time_bucket, equipment_id, inspection_qty, ng_qty
필수 laminator_profile.csv 설비 조건과 불량 집중 시간 연결 sample_time, recipe_id, process_time_sec, upper_temp_c, vacuum_kpa, pressure_kpa
권장 equipment_alarm.csv 알람과 불량 발생 시간 연계 alarm_time, equipment_id, alarm_code, alarm_name, severity, duration_sec
권장 bom_recipe_lot.csv 자재/BOM/Recipe 반복 패턴 분석 module_id, product_model, cell_lot, eva_lot, recipe_id, recipe_version
