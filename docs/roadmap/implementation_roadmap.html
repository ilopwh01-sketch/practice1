Implementation Roadmap

Laminator AI 업무 자동화 구현 로드맵

파일 기반 MVP에서 시작해 Profile/알람 연계, 이미지 분석 확장까지 단계적으로 구현하는 계획입니다.

1. 단계별 구현 계획

초기 목표는 “완전 자동 원인 확정”이 아니라, 담당자가 빠르게 검증할 수 있는 근거 중심 대시보드를 만드는 것입니다.

Phase 0

샘플 데이터/요건 정리

비식별 샘플 데이터와 BRD/PRD를 기반으로 분석 범위를 확정합니다.

  • 샘플 CSV/TXT 준비
  • 이상 징후 기준 정의
  • 화면 설계서 작성
Phase 1

파일 기반 MVP

CSV/엑셀 파일을 읽어 HTML 보고서와 분석 엑셀을 생성합니다.

  • 07-07 기준 집계
  • 불량 Pareto
  • 설비/시간 Heatmap
  • 수량 불일치 탐지
Phase 2

원인 후보 고도화

Profile, 알람, 불량 이벤트를 연결해 AI 원인 후보와 신뢰도를 표시합니다.

  • 공정 time/온도/진공도 분석
  • 알람 전후 30분 연계
  • High/Medium/Low 신뢰도
Phase 3

이미지 분석 확장

EL/AOI 이미지 유사도와 과검/오검 패턴을 연결합니다.

  • 이미지 참조 연결
  • 유사 불량 검색
  • 불량 이미지 학습 검토

2. 1차 MVP 산출물

산출물 내용 완료 기준
팀장 보고용 HTML 금일 핵심 이슈, KPI, Pareto, Heatmap, 원인 후보, 조치 사항 HTML 파일 1개로 열람 가능
분석 엑셀 Overview, Pareto, 설비별 NG율, 시간 Heatmap, Evidence Log 담당자가 숫자 검증 가능
검증 로그 수량 불일치, 재판정, 재투입, 컬럼 누락 경고 최종 승인 전 확인 가능
운영 가이드 파일 입력 순서, 결과 확인 순서, 보안 주의사항 라인 PC/사내망 PC 기준 실행 가능

3. 운영 시나리오

순서 작업 담당 결과
1 라인 PC 또는 사내망 PC에서 데이터 파일 다운로드 공정 담당자 CSV/엑셀 입력 파일 준비
2 자동화 도구 실행 및 파일 업로드 공정 담당자 데이터 검증 및 집계
3 AI 대시보드와 분석 엑셀 확인 공정 담당자 원인 후보와 근거 검토
4 팀장 보고 전 최종 문구 승인 공정 담당자 보고 자료 확정
5 설비 점검, Recipe 확인, 재발 모니터링 수행 공정/설비 담당자 불량 감소 활동 연결

4. 보안 및 승인 기준

항목 기준
실행 환경 원본 데이터 반출 금지 조건에 맞춰 라인 PC 또는 사내망 PC 실행을 기본으로 한다.
외부 공유 비식별 샘플 데이터와 결과 화면만 과제/발표용으로 사용한다.
AI 결과 승인 원인 후보 확정, 조치 계획, 팀장 보고 문구는 담당자가 최종 승인한다.
표현 원칙 AI는 “원인 확정”이 아니라 “원인 후보”, “확인 필요”, “연관 가능성”으로 표현한다.
