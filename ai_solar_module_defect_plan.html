불량 데이터 AI 분석 공정 개선 수율 향상 예지 품질

기획 배경

태양광 모듈 제조는 셀 스트링, 라미네이션, EL 검사, 프레임 조립, 최종 검사로 이어지는 복합 공정이며, 불량은 단일 요인보다 설비 상태, 공정 조건, 자재 특성, 작업 환경이 결합된 결과로 발생한다. 따라서 단순 불량률 집계만으로는 원인 후보를 빠르게 좁히기 어렵다.

본 기획은 공정 데이터와 불량 이력을 통합한 뒤 AI 분석을 적용하여 불량 패턴을 정량화하고, 작업자가 즉시 판단할 수 있는 KPI, 그래프, 개선 포인트 형태로 결과를 제공하는 것을 목표로 한다.

구현 방법

1

데이터 수집

공정 조건, 검사 결과, 설비 ID, LOT, 작업조, 불량 코드 데이터를 분석 가능한 표준 구조로 정리한다.

2

전처리

결측, 이상값, 중복 데이터를 정제하고 공정 단계별 비교가 가능한 변수 체계로 변환한다.

3

AI 분석

불량 분류, Pareto, 설비 집중도, CTQ 후보 탐색, 이상 징후 탐지를 통해 원인 후보를 압축한다.

4

리포트화

분석 결과를 시각화 리포트로 구성하고 원인 후보와 개선 우선순위를 명확히 제시한다.

기대효과

불량 원인 파악 시간 단축

수작업 집계 중심의 탐색 시간을 줄이고 핵심 원인 후보를 빠르게 확인한다.

수율 개선 활동 우선순위화

불량 코드, 라인, 설비, 작업조별 영향도를 비교해 개선 대상을 객관적으로 선별한다.

품질 리스크 조기 감지

공정 조건 변화와 NG율 상승 신호를 연결해 반복 불량의 초기 징후를 관리한다.

보고 자동화 기반 확보

품질 리포트 구조를 표준화해 일별, 주별 분석 자동화로 확장한다.

차별점

구분 기존 방식 본 프로젝트
분석 방식 불량률 집계 중심 AI 기반 패턴 탐색, 설비 집중도, 조건 영향도 분석
활용성 사후 보고 중심 개선 우선순위와 현장 조치 의사결정 연결
산출물 엑셀 또는 정적 문서 불량 원인 후보, AI 위험도 점수, 개선 우선순위 도출

RESEARCH DESIGN · P4

연구 설계 및 현업 적용 시나리오

P4

연구 질문

  1. 태양광 모듈 공정의 불량 발생은 특정 공정 조건, 설비, 작업 시간대에 통계적으로 집중되는가?
  2. AI 모델은 불량 코드별 주요 원인 후보를 어느 정도 설명 가능하게 제시할 수 있는가?
  3. AI 기반 분석 결과는 현장 개선 활동의 우선순위 결정 시간을 단축시키는가?

핵심 가설

  1. 라미네이터 진공도와 압력 Profile 변동은 CRACK 발생률과 유의미한 상관관계를 가진다.
  2. 특정 설비와 시간대에서 높은 NG율이 관찰될 경우 설비 편차 또는 조건 Drift 가능성이 높다.
  3. 불량 Pareto와 CTQ 후보를 함께 제시하면 개선 액션의 선택 정확도가 높아진다.

분석 방법론 설계

분석 단계 사용 데이터 적용 방법 판단 기준
기초 통계 LOT, 라인, 설비, 불량 코드, 검사 결과 NG율, DPMO, Pareto, 공정별 분포 비교 상위 불량 코드와 집중 설비 확인
원인 후보 탐색 온도, 압력, 진공도, 작업조, 시간대 상관분석, 그룹 간 평균 비교, 이상치 탐지 불량군과 정상군의 차이가 큰 CTQ 후보 선별
AI 모델링 전처리 완료된 공정 변수와 불량 라벨 분류 모델, Feature Importance, SHAP 해석 예측 성능과 설명 가능성의 균형 확보
현장 검증 개선 전후 수율, 설비 점검 이력, 재발률 A/B 비교, 전후 NG율 비교, 재발 모니터링 NG율 감소와 조치 리드타임 단축 여부

현업 페르소나별 활용 시나리오

공정 엔지니어 김민중 · 라미네이터 조건 최적화 담당

관심사: 설비 편차, Profile Drift, 공정 조건 표준화, 재발 방지 대책

활용: LAM-03처럼 NG가 집중되는 설비를 찾아 조건 변경과 점검 계획을 수립한다.

품질 엔지니어 불량 원인 분석 및 검증 담당

관심사: 불량 코드별 원인 후보, LOT 추적, 검사 결과 신뢰도

활용: Pareto와 CTQ 후보를 근거로 불량 원인 후보를 검증하고 개선 효과를 확인한다.

생산 관리자 수율 및 납기 관리 담당

관심사: 수율 손실, 조치 리드타임, 월별 개선 성과

활용: KPI 대시보드로 리스크 공정을 확인하고 개선 과제의 우선순위를 승인한다.

논문형 완성도를 위한 보완 항목

  • 데이터 정의서: 컬럼명, 단위, 수집 주기, 결측 처리 기준 명시
  • 모델 검증: Accuracy뿐 아니라 Recall, F1-score, Confusion Matrix 제시
  • 설명 가능성: Feature Importance와 SHAP 기반 원인 후보 해석
  • 한계점: 관측 데이터 기반 분석이므로 직접적인 인과관계 단정은 제한

최종 보고서 문장 방향

본 프로젝트는 단순 불량률 집계가 아니라 태양광 모듈 제조 공정의 품질 변동성을 데이터 기반으로 해석하고, AI 모델의 예측력과 설명 가능성을 함께 활용하여 현장 개선 의사결정의 근거를 제공하는 것을 목표로 한다.
