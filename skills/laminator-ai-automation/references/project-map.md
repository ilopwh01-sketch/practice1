# Project Map

Use this reference when deciding which project files to update.

## Entry Points

- `docs_portal.html`: main package portal.
- `index.html`: original interview tool.
- `codex_project_requirements.html`: Codex operating requirements and CSV column inspection.
- `CODEX_PROJECT_REQUIREMENTS.md`: markdown version of Codex operating rules.

## Submission Documents

- `docs/requirements/BRD_Laminator_AI_Automation.md`: business problem, KPI, scope, risks.
- `docs/requirements/PRD_Laminator_AI_Automation.md`: functions, input/output, screens, acceptance criteria.
- `docs/requirements/brd_detail.html`: BRD presentation HTML.
- `docs/requirements/prd_detail.html`: PRD presentation HTML.
- `docs/requirements/requirements_portal.html`: submission requirement traceability.

## Interview Documents

- `docs/interviews/question_memo.txt`: free-form user memo. Read this first when requested.
- `docs/interviews/*.html`: interview forms and summaries.

## Dashboard And Design

- `docs/dashboard/laminator_ai_dashboard.html`: real CSV-driven analysis dashboard.
- `docs/dashboard/final_output_example.html`: final mock report for feedback.
- `docs/design/screen_visualization_design.html`: UI and visualization spec.

## Data And References

- `sample_data`: dummy CSV/TXT data.
- `sample_data/upload_test_crack_bubble`: dashboard upload test CSV set.
- `docs/data/data_dictionary.html`: sample data explanation.
- `docs/references/paper_reference.html`: literature reference page.
- `docs/references/pv_root_cause_framework.html`: professional RCA framework.

## Recommended Update Order

1. User-facing mock or dashboard.
2. BRD/PRD if the requirement changed.
3. Screen design or data dictionary if structure changed.
4. README/setup/Codex requirements if usage changed.
