Codex 프로젝트 요구사항 탭

이 화면은 제출용 BRD/PRD가 아니라, Codex가 day3 프로젝트를 계속 작업할 때 기준으로 삼는 운영 요구사항입니다.

1. 프로젝트 기준

day1과 day3가 섞여 보이는 문제를 막기 위한 기준입니다.

현재 프로젝트 C:\Users\QCELL\Desktop\A1\day3
이전 Git 폴더 C:\Users\QCELL\Desktop\A1\day1은 이전 작업 폴더이며 이번 과제 산출물 기준이 아님
전체 포털 docs_portal.html
Codex 기준 파일 CODEX_PROJECT_REQUIREMENTS.md
앞으로 “프로젝트”라고 하면 기본적으로 day3 폴더를 의미합니다.

2. Codex 작업 원칙

인터뷰는 HTML

사용자가 인터뷰를 요청하면 항상 HTML 질문지 또는 요약 화면으로 만든다.

메모장은 먼저 읽기

“메모장” 요청 시 `docs/interviews/question_memo.txt`를 기준으로 반영한다.

피드백 반영 순서

피드백용 HTML 산출물 수정 후 BRD, PRD, 화면설계, 대시보드 스펙에 반영한다.

제출 문서와 운영 기준 분리

`docs/requirements`는 제출용, 이 탭은 Codex 작업 운영용이다.

원본 데이터 보안

원본 설비 데이터 외부 반출 없이 로컬 또는 비식별 샘플 기준으로 작업한다.

AI 역할 제한

AI는 원인을 확정하지 않고 원인 후보와 검증 우선순위를 제안한다.

3. 주요 산출물 연결

산출물 역할 파일
전체 문서 포털 제출 패키지 시작 화면 docs_portal.html

메모장 사용자 피드백 임시 수집 question_memo.txt

4. 현재 상태

항목 상태 메모
day3 산출물 패키지 진행 중 문서, 대시보드, 샘플 데이터, 논문 RCA 화면 생성 완료
최종 산출물 예시 피드백 대기 사용자가 예시 화면을 보고 최종 방향 피드백 예정
논문 기반 RCA 강화됨 문헌 근거, 경쟁 가설, 신뢰도 산식 추가
프로젝트 기준 정리 정리됨 day3가 현재 프로젝트 기준임을 명시
프로젝트 CSV 불러오기 추가됨 sample_data CSV 선택, 컬럼 구조 확인, 필수 컬럼 누락 표시 가능

5. 프로젝트 CSV 불러오기

이 탭은 CSV 컬럼 구조 확인용입니다. KPI와 분석 결과를 실제로 바꾸려면 AI 원인 분석 대시보드의 CSV 불러오기를 사용합니다.

권장 위치: sample_data 또는 sample_data/general_pv_module 폴더의 CSV를 선택하세요.

구분: Codex 프로젝트 탭은 요구사항/컬럼 검증용, AI 원인 분석 대시보드는 CSV 반영 분석용입니다.

6. 미확정 항목

이 항목들은 제출 문서에도 영향을 주는 프로젝트 운영 질문입니다.

  • DB/MES 활용 범위
  • 실제 실행 환경: 라인 PC, 사내망 PC, 별도 분석 PC 중 선택
  • 사람 최종 승인자와 승인 항목
  • 실제 현장 데이터 컬럼명
  • EL/AOI 원본 이미지 활용 가능 범위
