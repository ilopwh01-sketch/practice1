# Laminator AI 업무 자동화 샘플 데이터

이 폴더는 `일일 설비/불량 현황 보고서 자동 작성` 과제 설명에 사용할 수 있는 비식별 더미 데이터입니다.

## 파일 구성

- `daily_production_summary_2026-05-20.csv`
  - 07시-07시 기준 설비별 생산/검사/불량 수량 요약
- `defect_events_2026-05-20.csv`
  - 불량 발생 이벤트 단위 데이터
- `equipment_alarm_2026-05-20.csv`
  - Laminator 설비 알람 이력
- `laminator_profile_snapshot_2026-05-20.csv`
  - 설비 Profile 주요 CTQ 스냅샷
- `manual_memo_2026-05-20.txt`
  - 담당자 수기 메모 예시

## 샘플 데이터 의도

- LAM-03 설비에서 14시대 `CRACK` 불량이 집중 발생하도록 구성했습니다.
- 생산 수량, 검사 수량, 불량 수량 간 일부 불일치가 발생하도록 구성했습니다.
- 14시대 LAM-03에서 진공도 및 압력 Profile 특이점이 보이도록 구성했습니다.
- 설비 알람과 불량 집중 시간이 일부 겹치도록 구성했습니다.

## 자동화 보고서에서 확인할 포인트

1. 07시-07시 기준 생산량, 검사량, 불량 수량 집계
2. 설비별 불량률 비교
3. 불량 유형 Pareto
4. 특정 설비/시간대 불량 집중 탐지
5. 설비 알람과 불량 이벤트 시간 연관성 확인
6. Profile 특이값 확인
7. 생산/검사/불량 수량 불일치 경고
